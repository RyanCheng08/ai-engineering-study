AI 工程学习中心
================

公开内容包含第一至第三章的完整学习笔记、同页自测和术语解释：
第一章 1.1～1.7：70 道自测题，49 个术语，以及 1.2～1.7 六节讲解视频。
第二章 2.1～2.5：73 道题（50 道补充自测 + 23 道原笔记练习），54 个术语。
第三章 3.1～3.7：115 道题（70 道补充自测 + 45 道原笔记练习），67 个术语。
第三章原有 53 个问句经 8 次同题合并整理为 45 题，并保留原来的不同问法。
第二、三章的原练习与参考答案集中于自测区；教学正文保留讲解、例子、表格和代码。
原文没有单列答案的题目会明确标注答案根据正文整理。
页面可搜索、打印，并提供各章题目版和答案解析版 TXT 下载。
第二、三章没有新增视频；第一章原有视频、字幕及旁白稿继续提供下载。

本地构建
--------
需要 Node.js 20 或以上、npm 和 Python 3.10 或以上（python 命令应指向 Python 3）。
在仓库根目录执行：

    npm ci
    npm test
    npm run build

npm test 包含文件自动保存测试、18 项作答与收藏状态兼容测试，
以及公开文件白名单、原题路由、旧书签和私有文件边界测试。
构建顺序为：第一章 → 第二章 → 第三章 → 第二/三章内容验证 → 组装公开站点。
第二章从源笔记重新提取原题；第三章构建时进行同题合并和原题迁移。
两个验证器检查正文保留、原题与答案覆盖、题数、术语、脚本和复习链接。
npm 锁定 marked 17.0.5；Python 构建步骤只使用标准库。
也可分别运行：

    npm run build:chapter-one
    npm run build:chapter-two
    npm run build:chapter-three
    npm run verify
    npm run build:site

第二、三章使用第一章生成的页面结构，因此应先完成第一章构建。
输出目录是 _site。双击 _site/index.html 可以离线打开，
也可在仓库根目录执行 python -m http.server 8000 --directory _site，
再打开 http://localhost:8000/。

GitHub Pages
------------
仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
推送 main 分支或在 Actions 手动运行发布工作流，会测试、构建并发布 _site。
任何测试、内容验证或链接检查失败都会阻止上传及部署。
工作流使用 GitHub 提供的 Pages 权限和身份令牌，无须另配部署密钥。
页面只使用相对站内路径，可放在 https://用户名.github.io/仓库名/ 子路径下。

公开文件范围
------------
scripts/build-site.py 仅组装公开首页、第一至第三章学习页、第一章旧自测入口、
六份题库 TXT，以及 讲解视频/成片 中获准的成片和学习附件。
构建所需的课程源 Markdown、题库数据和脚本随仓库提交，但不复制到 _site。
允许的视频附件是 mp4 / vtt / srt / jpg / png、index.html、使用说明.txt、
每节的 *-旁白稿.txt、课程目录.json 和 1.2～1.7 的章节时间轴 JSON。
视频目录中的其他文件会导致构建失败；生成日志和媒体诊断不进入发布目录。
站点不收集履历文件、私人首页、联系方式或本机作答与收藏记录。
笔记里的履历入口会移除，飞书内部图片授权链接会替换为公开学习主线入口。
构建会拒绝符号链接及 Windows 目录连接，校验站内相对链接、真实题号和授权串。
脚本允许覆盖相同公开文件，不自动删除文件；若 _site 存在非白名单旧文件，会报错。

作答进度与经典问题收藏
----------------------
在自测题上点击“☆ 收藏经典问题”，再点击“本章收藏”即可跨小节复习收藏题。
每章分别保存自己的收藏；收藏不影响得分，清空答案或重做不会取消收藏。
作答与收藏记录尝试保存于当前浏览器的本地存储，不上传服务器。
旧版作答备份仍可导入，原有题目 ID、答案及自评保持兼容。
不同浏览器、设备和站点地址之间不会自动同步；清除站点数据可能删除记录。
可以导出“作答与收藏”JSON 备份，再在另一浏览器或设备导入。
本地 file:// 页面与 GitHub Pages 地址是不同存储位置，迁移时请使用导出、导入。

本机作答文件自动保存
--------------------
GitHub Pages 上的 HTTPS 页面可以使用浏览器的文件访问能力，无须增加后端。
在桌面 Chrome / Edge 的自测区点击“新建作答文件”，选择本机 JSON 文件并授权。
也可点击“连接已有文件”恢复记录；选项、文字答案、自评和收藏会自动写入文件。
只有文件写入并关闭成功才会显示“作答文件已保存”。关闭网页前请确认这个状态。
浏览器会尝试记住文件连接；重新打开后可能需要点击“恢复文件连接”重新授权。
文件与浏览器中的作答或收藏不同会显示选择提示，选择前不覆盖已有文件。
清除站点数据后文件仍保留，可以重新连接恢复；更换设备需自行复制文件。
不支持文件访问能力的浏览器继续使用自动浏览器保存和 JSON 导入导出。
“断开文件”停止自动写入，不删除本机文件。作答文件不会上传到公开仓库。
